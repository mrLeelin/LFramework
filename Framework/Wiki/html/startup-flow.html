Startup Runtime

从 LSystemApplication 到进入游戏

从热更入口创建 LSystemApplication 开始，追到 Component、Procedure、Provider、World、WorldHelper，再到业务开始游戏。

总览启动流程配置整理模块详解模块树WorldHelper类索引资源与构建新人清单

0. 前置链路

LSystemApplication 不是场景对象，它由热更入口创建。常见路径是：

LaunchPipelineRunner
  -> InitResourceTask
  -> LoadAssemblyTask
  -> HotfixEntryTask
  -> HotfixComponent.EnterHotfixAssembly()
  -> LFramework.Hotfix.Entry.HotfixEntryStart()

1. Entry.HotfixEntryStart

热更入口负责创建应用、拿到运行时组件、注册热更内容，并切到入口 Procedure。

Entry.HotfixEntryStart
  -> SingletonManager.AddSingleton<LSystemApplication>()
  -> LSystemApplication.ClearReflectionCache()
  -> get ProcedureComponent
  -> get HotfixComponent
  -> application.RegisterHotfixComponents(hotfixComponent)
  -> AddHotfixProcedure(procedureComponent, hotfixComponent)
  -> procedureComponent.ForceChangedProcedure(entranceProcedureType)

入口类型名来自 ProcedureComponent.EntranceHotfixProcedureTypeName。如果该类型不在 HotfixComponent.GetHotfixAssemblyAllTypes() 中，就不会进入业务流程。

2. LSystemApplication 构造

LSystemApplication 是热更运行时总拥有者，实现 ISystemProviderRegister、IWorldRegister、ISingletonUpdate、ISingletonLateUpdate。

LServices.Inject(this)
LServices.Register<ISystemProviderRegister>(this)
LServices.Register<IWorldRegister>(this)

后续 Procedure 不直接依赖应用对象，而是从 LServices 取 Provider/World 注册接口。

3. 热更 Component 注册

RegisterHotfixComponents 扫描 [HotfixComponentAttribute] 类型，要求继承 GameFrameworkComponent。

  1. 创建组件实例并设置 Parent。
  2. 按 BindType 或派生接口注册到 LServices。
  3. 所有组件创建后统一 LServices.Inject。
  4. 统一调用 AwakeComponent、StartComponent、SetUpComponent。

热更组件是跨流程长期服务，每帧由 LSystemApplication.Update 调用 UpdateComponent。

4. Procedure 进入

Entry.AddHotfixProcedure 扫描 [HotfixProcedureAttribute]，创建非抽象 Procedure，并加入 ProcedureComponent。强制切换入口后，真正进入 HotfixProcedureBase.OnEnter。

HotfixProcedureBase.OnEnter
  -> TryRegisterProvider(ProcedureState)
  -> TryRegisterWorld(ProcedureState)
  -> world.LinkProcedure(this)
  -> Injection.Inject(this)
  -> OnEnterProcedure(procedureOwner)

5. Provider 注册

Provider 通过 [BelongTo(procedureState, lifeCycle, sort)] 绑定流程，必须继承 SystemProviderBase。

ReferencePool.Acquire(providerType)
  -> RegisterCommonDataSync
  -> LServices.Register(interfaceType)
  -> LServices.Register(providerType)
  -> sort desc
  -> Injection.Inject
  -> AwakeComponent
  -> SubscribeEvent
  -> SetUp

Sort 越大越先初始化；ProviderLifeCycle.Forever 切流程不释放。

6. World 注册与进入游戏

World 同样用 [BelongTo] 绑定流程，但必须继承 WorldBase。

ReferencePool.Acquire(worldType)
  -> Injection.Inject(world)
  -> LServices.Register(interfaceType)
  -> LServices.Register(worldType)
  -> world.Initialized()
  -> _worldBase = world

WorldBase.Initialized 内部顺序：

ResolveFrameworkDependencies
  -> Subscribe(EventComponent)
  -> RegisterWorldHelper
  -> InitializeAllHelpers
  -> OnInitialized

业务真正“进入游戏”的落点通常在 World.OnInitialized 或入口 Procedure 的 OnEnterProcedure 中，触发 InstantiateHelperGame 和 StartHelperGame。

7. WorldHelper 自动注册

Helper 通过 [AutoWorldHelper(typeof(SomeWorld))] 绑定 World。

WorldBase.RegisterWorldHelper
  -> AutoRegisterWorldHelper.GetRegisterWorldHelper(worldType)
  -> HotfixComponent.GetTypesFromAttribute<AutoWorldHelperAttribute>()
  -> filter BindWorldType
  -> ReferencePool.Acquire(helperType)
  -> BuildWorldHelpers(helper)
  -> LServices.Register(helper interface)
  -> LServices.Inject(helper)
  -> helper.Initialize()

实现 IWorldUpdate 或 IWorldLateUpdate 的 Helper 会被 World 每帧更新。

8. 每帧与释放

LSystemApplication.Update
  -> hotfix component UpdateComponent
  -> provider UpdateComponent
  -> world Update

LSystemApplication.LateUpdate
  -> world LateUpdate

离开 Procedure 时，先执行业务 OnLeaveProcedure，再注销当前流程 Provider 和 World。Provider/World 都会注销服务、清理注入缓存并释放回 ReferencePool。

排查表

现象先看
没进入热更入口HotfixEntryTask、HotfixComponent.EnterHotfixAssembly
入口 Procedure 找不到EntranceHotfixProcedureTypeName、热更程序集类型字典
Provider 没创建BelongToAttribute.ProcedureState、是否继承 SystemProviderBase
World 没创建BelongToAttribute.ProcedureState、是否继承 WorldBase
WorldHelper 没注册AutoWorldHelperAttribute.BindWorldType、是否继承 WorldHelperBase
切流程后状态残留Provider 是否误设为 Forever
