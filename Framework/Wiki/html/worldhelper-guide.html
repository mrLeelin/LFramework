在 wiki 里应该怎么体现

WorldHelper 要体现成“World 下面的子系统树”，不是一堆平铺类名。每个 Helper 的详情都按同一套字段记录，这样新人能从模块关系、生命周期、依赖和调用关系读懂它。

进入模块树

第一层：模块入口

在 `模块树` 里选择 `WorldHelper 模块`，看到 `WorldHelperBase` 到所有子类的树状关系。

第二层：类详情

点击某个 Helper，右侧展示继承、方法、引用、被引用，以及专门的 `Wiki 记录模板`。

第三层：业务补充

自动索引只能告诉你结构；业务职责、资源释放、调用原因，需要按模板人工补齐。

固定记录模板

每个 WorldHelper 文档块都用这套结构。不要改成自由散文，否则新人无法横向比较不同 Helper。

HelperName
- 绑定 World：AutoWorldHelper(typeof(目标World))
- 所属流程：ProcedureState.xxx / 由哪个 Procedure 进入
- 对外接口：IxxxHelper，谁通过 LServices 获取
- 职责：一句话说明负责的局内子系统
- 生命周期：
  - Initialize：读取 World、订阅事件、准备状态
  - InstantiateWorld：异步创建实体/加载资源
  - StartGame：打开运行开关
  - OnUpdate/LateUpdate：运行中的帧逻辑
  - StopGame：关闭运行开关、停止行为
  - Clear：取消订阅、释放资源、清空引用
- 依赖：注入了哪些 Component / Provider / 业务接口
- 调用关系：被哪个 World 启动；被哪些系统调用；调用哪些 Helper
- 资源归属：创建了什么，在哪里释放
- 注意事项：运行开关、对象池、异步取消、空引用保护

使用路径

  1. 先看树：打开 模块树，选择 `WorldHelper 模块`。
  2. 再点类：点击 `WorldHelperBase` 或具体 Helper 子类。
  3. 看右侧模板：右侧会自动生成“Wiki 记录模板”，里面有能从代码推断的信息。
  4. 补业务信息：把 `TODO` 补成真实职责、调用方、资源释放点。
  5. 需要查全局关系：跳到 类索引 搜类名，看引用和被引用。

WorldHelper 的代码使用规则

问题结论
什么时候用 WorldHelper逻辑只在某个 World 生命周期内存在，例如局内刷怪、相机、结算、局内同步。
怎么绑定 World在 Helper 类上写 [AutoWorldHelper(typeof(YourWorld))]。
World 何时启动 HelperWorldBase 只自动调用 Initialize()；InstantiateHelperGame()、StartHelperGame()、StopHelperGame() 由具体 World 主动调用。
World 内部怎么取 Helper用具体类型：GetWorldHelper<ConcreteHelper>()。
外部系统怎么访问用业务接口走 LServices.Get<IYourHelper>()。
实现 Update 要注意什么实现 IWorldUpdate 或 IWorldLateUpdate 后必须有运行开关，例如 _running。

最小代码模板

[AutoWorldHelper(typeof(CombatWorld))]
public sealed class CombatSpawnHelper : WorldHelperBase, ICombatSpawnHelper, IWorldUpdate
{
    private CombatWorld _world;
    private bool _running;

    public override void Initialize()
    {
        _world = GetWorld<CombatWorld>();
    }

    public override UniTask InstantiateWorld()
    {
        return UniTask.CompletedTask;
    }

    public override void StartGame()
    {
        _running = true;
    }

    public void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        if (!_running)
        {
            return;
        }
    }

    public override void StopGame()
    {
        _running = false;
    }

    public override void Clear()
    {
        _running = false;
        _world = null;
    }
}

World 中的启动模板

protected override void OnInitialized()
{
    EnterWorldAsync().Forget();
}

private async UniTaskVoid EnterWorldAsync()
{
    await InstantiateHelperGame();
    StartHelperGame();
}

protected override void OnDeInitialized()
{
    StopHelperGame();
}
