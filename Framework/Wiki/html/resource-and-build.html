资源模式

ResourceComponentSetting.ResourceMode 决定资源后端：YooAsset 或 Addressable。

YooAsset 多包

  • packageId 是逻辑包 ID。
  • yooPackageName 是实际 YooAsset 包名。
  • 默认包为空时取第一个有效包。
  • 路由索引包通过 Routing 配置解析。
  • 构建包、更新包、下载计划由 YooAssetMultiPackageUtility 收集。

Addressables HasAsset

先查 catalog location，再查下载大小。Exist 表示本地已可用，NotReady 表示 catalog 未就绪或仍需下载，NotExist 表示 catalog 已就绪但 key 不存在。

定位顺序

  1. 确认 BuildSetting.buildType。
  2. 确认 ResourceComponentSetting.ResourceMode。
  3. 确认 isbuildDll、isBuildResources、isResourcesBuildIn。
  4. 确认平台 IPlatformConfig 是否写入正确 PlayerSettings。
  5. 确认资源输出路径和运行时加载路径一致。
