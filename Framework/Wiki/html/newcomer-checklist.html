第一天必须跑通

  1. Unity 打开主工程。
  2. 打开 LFramework/GameSetting。
  3. 找到当前工程的 ProjectSettingSelector。
  4. 确认 ResourceComponentSetting.ResourceMode。
  5. 确认入口 Procedure 配置。
  6. 进入 Play Mode，观察启动管线和热更入口日志。

问题入口

问题起点
启动卡住LaunchPipelineRunner.RunAsync
资源初始化失败InitResourceTask / ResourceComponentSetting
热更 DLL 没加载LoadAssemblyTask / HotfixComponent / HybridCLRSetting
Provider 没注册LSystemApplication.RegisterProvider.cs
World 没注册LSystemApplication.RegisterWorld.cs
构建失败BuildOrchestrator / BuildPipelineRunner

改框架前判断

  • 通用能力放框架，业务玩法不要塞框架。
  • 配置数据优先改 Setting 资产和 Setting 类型。
  • 平台打包差异放到 IPlatformConfig 或构建任务。
  • 资源问题先判断后端是 YooAsset 还是 Addressables。
