Component

Component 是框架级长期服务，继承 GameFrameworkComponent。当前基类不是 MonoBehaviour，实例由配置或热更扫描创建，由框架显式调用生命周期。

AwakeComponent
StartComponent
SetUpComponent
UpdateComponent
LateUpdate
ShutDown
RuntimeOnApplicationFocus / Pause / Quit

ComponentSetting.bindTypeName 绑定运行时组件类型；ComponentSettingExtension.CovertToComponent 会反射创建组件，并把 Setting 同名字段拷贝到组件字段。

适合放资源、下载、表格、UI、实体、通知、声音、计时器等跨流程基础服务。不适合放随玩法流程释放的业务状态。

HotfixComponent

HotfixComponent 是热更系统组件，负责加载 DLL、建立类型索引、按 Attribute 反查热更类型，并反射进入热更入口。

  • Editor：从当前 AppDomain 收集主逻辑程序集和热更程序集。
  • HybridCLR：先加载 AOT 元数据，再加载热更 DLL。
  • 加载成功后建立 _allTypes 和 _allAttributeTypes。
  • EnterHotfixAssembly 调用 LFramework.Hotfix.Entry.HotfixEntryStart。

后续热更组件、Procedure、Provider、World、WorldHelper 的扫描都依赖它的 GetTypesFromAttribute<T>()。

Provider

Provider 是随 Procedure 生命周期管理的系统服务，继承 SystemProviderBase，通过 [BelongTo(procedureState, lifeCycle, sort)] 绑定流程。

ReferencePool.Acquire
  -> RegisterCommonDataSync
  -> LServices.Register(interfaceType/providerType)
  -> sort desc
  -> Injection.Inject
  -> AwakeComponent
  -> SubscribeEvent
  -> SetUp

SystemProviderBase 提供事件组件注入、订阅/反订阅、UpdateComponent、OnStop、Fire、FireNow。

World

World 是当前 Procedure 的上下文容器，继承 WorldBase。一个流程最多有一个当前 World，保存在 LSystemApplication._worldBase。

WorldBase.Initialized
  -> ResolveFrameworkDependencies
  -> Subscribe(EventComponent)
  -> RegisterWorldHelper
  -> InitializeAllHelpers
  -> OnInitialized

Procedure 可以通过 GetLinkWorld<TWorld>() 找 World；World 可以通过 GetLinkProcedure<TProcedure>() 找当前 Procedure。

WorldHelper

WorldHelper 是 World 内部的子系统，继承 WorldHelperBase，通过 [AutoWorldHelper(typeof(SomeWorld))] 自动绑定 World。

AutoRegisterWorldHelper
  -> scan [AutoWorldHelper]
  -> filter BindWorldType
  -> ReferencePool.Acquire
  -> SetWorld
  -> Register interface to LServices
  -> Inject
  -> Initialize

Helper 可实现 IWorldUpdate、IWorldLateUpdate 进入 World 的更新列表。World 可批量调用 InstantiateHelperGame、StartHelperGame、StopHelperGame。

模块选择表

需求放哪里原因
全局基础服务Component生命周期跨流程，配置驱动
热更 DLL 和类型索引HotfixComponent热更类型扫描源
当前流程业务系统Provider绑定 ProcedureState，可排序和释放
当前玩法上下文World一次流程一个上下文，持有 Helper
World 内部子系统WorldHelper拆分世界逻辑，可自动注册和更新
单个 UI 窗口逻辑UIBehaviour / Window受 UIComponent 管理
单个实体逻辑EntityLogic受 EntityComponent 管理

边界警告

  • 不要把业务玩法状态塞进长期 Component。
  • 不要让 WorldHelper 绕过 World 注册全局状态。
  • Provider 不要手动 new 依赖，优先用 [Inject] 或 LServices。
  • Provider/World 的业务接口选择会影响 LServices 注册结果。
  • IInjectable 是生成注入标记，不是业务接口。
